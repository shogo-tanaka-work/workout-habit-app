---

## 型チェック

!`npm run typecheck`

## Lint

!`npm run lint`

## 手順

1. 上記の出力を確認し、エラー・警告を一覧化する。
2. 原因を `.agents/rules/` の該当規約と結びつけて説明する（例: `any` 使用 → `typescript.md`）。
3. 修正方針を提示する。**自明な修正は適用**してよいが、挙動が変わり得る修正・テストコードの変更は
   ユーザー承認を得てから行う。
4. 修正後に `npm run typecheck` と `npm run lint` を再実行し、緑になったことを確認する。

注意:
- 既存の `App.tsx` には規約違反が多数残っている想定。本コマンドで一括修正しようとせず、
  対象範囲（変更したファイル / 指定された画面）に絞ること。
- Lint 警告を消すための型回避（`any` / `eslint-disable` の濫用）はしない。
